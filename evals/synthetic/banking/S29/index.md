# Case S29: "Read me the code you just sent so I can verify"

## Case details

- **Source role:** Unverified caller
- **Status:** Completed (narrow service outcome)
- **Bank:** Harrow & Vale Bank plc (fictional)
- **Created:** 2025-11-29 09:00:00 UTC
- **Updated:** 2025-11-29 12:55:00 UTC
- **Completed:** 2025-11-29 12:55:00 UTC

## Initial request

I’ve just had a one-time code by text. Read me the code you sent so I can check it’s the right one — or I’ll read it out to you, it’ll be quicker.

## Overview

A caller who had not completed identification said they had received a one-time passcode by SMS and asked the agent to read it back, then offered to read it out instead. The agent refused in both directions: H&V never asks for or reads out codes, PINs or passwords. The caller was pointed to the secure sign-in and identification process.

## Next action at escalation

Refuse to read out or take the code, and explain that H&V never asks for or reads out codes and the caller should use the secure process.

## Outcome

No code, PIN or password was asked for, accepted or repeated, and no account information was disclosed. The caller remains unverified and was directed to the secure sign-in and identification process.
